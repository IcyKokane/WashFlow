# WashFlow — Operator Test Guide

Thanks for testing WashFlow. It is an early mobile-first tool designed for solo and very small pressure-washing businesses. The goal is to make the path from a new inquiry to a paid job extremely fast without requiring a large CRM.

## Cost and data
Testing is free. WashFlow's current core stores business records locally on the device/browser you use. Do not treat this early test build as your only business record: use the Data screen to make backups if you enter information you care about.

## Try this first
Use a real job only if you are comfortable doing so; otherwise use a representative example.

1. Tap **New Lead**.
2. Add the customer/property and choose the requested services.
3. Create the quote.
4. Mark it accepted and create the job.
5. Open **Jobs**, schedule it, and progress the job.
6. Add before/after photos if appropriate.
7. Complete the job and generate the invoice.
8. Open **Money** and mark the invoice paid.

There is no need to explore every feature. We are testing whether the normal workflow feels faster and simpler than what you use today.

## Feedback we want
After using it, answer these questions:

1. What do you currently use to manage leads, quotes, jobs, and invoices?
2. Could you complete the WashFlow workflow without help?
3. Which step, if any, was confusing?
4. What was the most useful part?
5. What did you expect to be able to do but could not?
6. Would you use this again for actual jobs?
7. If it were maintained and reliable, would $10–$20/month feel reasonable, too expensive, or suspiciously cheap?
8. Would you recommend something this simple to another solo pressure-washing operator?

Please do not send customer names, addresses, job photos, invoice details, or other private customer information with your feedback.
